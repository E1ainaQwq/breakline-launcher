# Hero / 卡片素材放这里

把文件按下面的名字丢进这个目录，**重新构建**（`npm run build`）即可生效。

> ⚠️ **2026-09-18 更正**：以前这句只对 `hero-*` 成立 —— `season` 当时根本没接线（代码里是写死的占位块），
> 文件放进去也不会显示。现在两者都是 glob 自动发现：**文件名对上就行，不需要改代码**。
> 图片一律存 **JPEG（质量 88）**：同一张图 PNG 约 2 MB、JPEG 约 0.15 MB，
> 六张图合计从 10.4 MB 降到 0.98 MB —— 启动器每次更新都要重新下发这些字节，玩家为此多等的时间是实打实的。

| 文件名 | 用在哪 | 建议尺寸 | 现状 |
| --- | --- | --- | --- |
| `hero-1` … `hero-5`（png/jpg/webp 都行） | 首页 Hero 主视觉，**每次启动随机轮换一张** | 1280×560 左右，横向；深色场景更好压字 | 缺（现在是带网格的占位块） |
| `season`（png/jpg/webp 都行） | 右侧第一张卡片（战局/赛季位） | 600×260 左右 | **已放**（season.jpg 1200×900） |
| `logo.png` | 标题栏左上（现在是内联 SVG 三角，可保留） | 64×64 以上，透明底 | 用 SVG，可不补 |

## 关于 Hero 的三条经验

1. **要深色、低对比的场景图**：上面会压 `linear-gradient` 黑色遮罩 + 左下角
   `DELTA CRAFT` 白色粗体标题，图太亮会让标题糊掉。
2. **主体别放在左下角**：标题和手写那句都在左下与右下，人/建筑主体建议偏中上。
3. **5 张足够**：轮换的目的是"每次打开不一样"，不是图集；太多反而难挑。

## 检查方法

放好图后跑：

```bash
node tools/../src/renderer/../../launcher/tools/...   # 不需要；直接看截图即可
```

在 `launcher/` 下执行 `npm run build`，然后用 `--uishot` 截图看一眼：

```powershell
& "dist\win-unpacked\Delta Launcher.exe" --uishot --shot-dir C:\temp\shots
```

`00-boot.png` / `05-home.png` 就是首页效果。
